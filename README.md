# tdx-rnd

TouchDesigner components.

## Analog

- [ntsc-td](https://github.com/olegchomp/ntsc-td) — NTSC composite and VHS. Encoding, head switching, and ringing.
- [tdx-modulation](analog/tdx-modulation) — grayscale scanline effect. Brightness shifts the phase of a cosine carrier.
- [tdx-crt](analog/tdx-crt) — draws the input as a signal on a CRT tube. The shader runs on a GLSL TOP. Controls live on the parent CRT page.

## Unreal Engine

- [tdx-livelink](unrealengine/tdx-livelink) — sends 61 ARKit curves to Unreal over UDP. MetaHuman drives the face.
